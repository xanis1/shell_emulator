# Эмулятор командной строки (Вариант №30)

Консольный эмулятор операционной системы, работающий с виртуальной файловой системой (VFS) на базе ZIP-архива. Поддерживает выполнение стартовых скриптов, перехват ошибок и базовую навигацию по директориям.

## Поддерживаемые команды
* `ls` — вывод списка файлов и папок в текущей директории архива.
* `cd <путь>` — переход в указанную директорию. Поддерживает возврат назад (`cd ..`) и в корень (`cd /`).
* `conf-dump` — служебная команда для вывода текущих конфигурационных параметров.
* `exit` — завершение работы эмулятора.

## Требования и запуск
Согласно требованиям, сам тестовый архив не загружается в репозиторий (исключен через `.gitignore`). Перед запуском необходимо создать локальный архив `archive.zip` в корневой папке проекта.

**Пример команды запуска:**
```cmd
py src/emulator.py --vfs ./archive.zip --script ./start.txt
