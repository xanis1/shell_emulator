# Эмулятор оболочки ОС

## 1. Общее описание
Эмулятор командной строки UNIX-подобной ОС. Поддерживает REPL (интерактивный режим ввода). Выполнен 1 этап (вариант 30).

## 2. Описание всех функций и настроек
* `cmd_ls(args)`: функция-заглушка для вывода команды ls.
* `cmd_cd(args)`: функция-заглушка для команды cd (обрабатывает ошибку неверного количества аргументов).

## 3. Команды для сборки проекта и запуска тестов
* Запуск эмулятора: `./run.sh` (или `python src/emulator.py`)
* Запуск тестов: `python -m unittest discover tests`

## 4. Примеры использования
vfs:/ $ ls -l
Вызвана команда: ls
Аргументы: ['-l']
